ReAct Chain stands for Reason + Act.

It is an AI agent technique where the LLM doesn't immediately give the final answer. Instead, it follows a loop:

Reason (Think) – Decide what to do next.
Act – Use a tool (calculator, search, database, API, etc.).
Observe – Look at the tool's output.
Repeat – Continue reasoning if needed.
Final Answer – Respond to the user.
